Can the action be undone?

From Securing Enterprise AI: A Vendor-Agnostic Method · Ankush Chowdhary

About this lesson. Every action an AI system can take falls into one of seven classes, from Read to Delete. This lesson shows how grading each action by whether it can be undone lets an agent move fast on reversible actions and stop for a human on the few that can't be recalled. It is taken from the middle of the course, which teaches a vendor-agnostic method to assess, classify, control, attack and secure enterprise AI.
Built on the AI Control Architecture, an open framework.
